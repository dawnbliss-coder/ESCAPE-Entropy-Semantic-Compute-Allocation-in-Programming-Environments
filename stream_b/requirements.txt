# current transformers' tokenizer API, so it's pinned to a compatible older transformers
# here rather than whatever Stream A uses for the BLT patcher (that's a separate venv
# concern, not a shared-requirements conflict). Two things are REQUIRED for benepar to
# import successfully, not just this pin:
#   1. transformers==4.30.2 (not the current 5.x line: T5Tokenizer lost
#      build_inputs_with_special_tokens that benepar's retokenizer calls)
#   2. env var PROTOCOL_BUFFERS_PYTHON_IMPLEMENTATION=python must be set BEFORE
#      transformers/benepar are imported (the installed `protobuf` package is too new for
#      transformers' bundled sentencepiece_model_pb2.py otherwise - "Descriptors cannot be
#      created directly"). Set this in code: os.environ.setdefault(...) at the top of any
#      script that imports benepar/spacy, or export it in your shell before running.
# Also run once after installing: python -m spacy download en_core_web_md
#                                  python -c "import benepar; benepar.download('benepar_en3')"
